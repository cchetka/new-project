## Как войти в свой аккаунт Google

### 1. На компьютере
1. Откройте браузер (Chrome, Firefox, Safari, Edge).
2. Перейдите на [accounts.google.com](https://accounts.google.com).
3. Нажмите кнопку **Войти** в правом верхнем углу.
4. Введите ваш адрес электронной почты (Gmail) и пароль.
5. При наличии двухфакторной аутентификации подтвердите вход через телефон.

### 2. На телефоне (iPhone / iOS)
- **Через приложения**: установите Google / Gmail / Chrome из App Store и нажмите **Войти**.
- **В настройках iOS**: откройте **Настройки** → **Почта** (или **Учетные записи**) → **Добавить учетную запись** → выберите **Google** и авторизуйтесь.

### 3. Как проверить, к каким устройствам подключен аккаунт
Перейдите на страницу [Безопасность Google — Ваши устройства](https://myaccount.google.com/device-activity), чтобы увидеть список всех активных компьютеров и телефонов.
